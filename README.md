# D&D Pulse — Hero prototype V1

Prototype visuel autonome de la bannière d'ouverture.

- Hero plein écran avant toute navigation
- Cycle D&D PULSE → valeurs → accroche
- Pulsations lumineuses
- Particules interactives au curseur
- Clic dans le hero = impulsion locale
- Navigation uniquement après le hero, sticky ensuite
- Réduction des effets selon la taille d'écran

Branche : `prototype/hero-pulse-v1`

Pour tester : ouvrir `index.html` dans un navigateur ou utiliser un serveur statique local.

Ce prototype utilise uniquement HTML/CSS/JS, sans dépendance. Le but est de valider le mouvement, le rythme et la direction artistique avant d'intégrer une stack définitive.
